# PRISM AI BUDDY

### A Small Device. A Bigger World of Possibilities.

PRISM AI BUDDY is an experimental interactive electronics project developed by **TWINSYNC IV TECHNOLOGY**.

The project explores compact visual interfaces, embedded systems and AI-assisted interaction using ESP32 hardware.

## Project Vision

To explore a compact interactive companion featuring a visual interface, connected intelligence and an engaging user experience.

## Hardware

Current experimental platform:

- ESP32 development board
- 1.54-inch ST7789 TFT display
- Semi-reflective optical cube
- Supporting electronic components

## Current Prototype

The prototype includes:

- TFT display interface
- Custom visual face
- Display text and graphics
- Experimental holographic-style visual presentation

## Research and Development

Future development areas:

- AI assistant connectivity
- Interactive responses
- Improved graphical interface
- Voice input and output exploration
- Wireless communication
- Additional visual effects
- Compact enclosure design

These are development goals, not necessarily completed features.

## Technology

- ESP32
